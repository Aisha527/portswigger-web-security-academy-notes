# Blind OS Command Injection — Out-of-Band Interaction


## Definition



**Out-of-Band (OOB) OS Command Injection** is a type of blind OS command injection where the command executes, but 
its output is not returned in the HTTP response and cannot be redirected to an accessible location.



Instead, an **external interaction** is used to confirm command execution.



## Lab



**Lab:** Blind OS command injection with out-of-band interaction

**Difficulty:** Practitioner

**Function:** Feedback



### Goal



Trigger a **DNS lookup to Burp Collaborator**.



## Exploitation Concept




`nslookup` can be used to perform a DNS lookup:



```bash

nslookup YOUR-COLLABORATOR-DOMAIN


```



The Collaborator domain is generated by Burp Collaborator.



When the vulnerable server executes the command:



```text

Injection

    ↓

OS command execution

    ↓

nslookup

    ↓

DNS request

    ↓

Burp Collaborator

    ↓

Interaction detected

```



The DNS interaction confirms that the injected command was executed.



## Why OOB?



Unlike the previous labs:



```text

Lab 1 → Output in HTTP response

Lab 2 → Time delay

Lab 3 → Output redirection

Lab 4 → External interaction

```



The application provides no useful response and does not allow us to redirect the output to an accessible file, so 
we use an external DNS interaction as the evidence of execution.



### Key Takeaway



> **OOB OS Command Injection** uses an external interaction, such as a DNS lookup, to confirm command execution 
when the application provides no direct way to observe the result.
